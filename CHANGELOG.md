# Releases

## 0.4.0 — incident response and developer onboarding

- Registered host-allowed receivers, Standard Webhooks HMAC signing, transactional
  bodies, restart recovery, bounded retry, visible dead letters and scoped replay.
- Dashboard delivery state, one-time secrets and named-role connection controls.
- One-command actual digit-model quickstart: signed receiver, receipt loss,
  application review/outcome, named mitigation and owned-service cleanup.
- Native async Python/Node hooks, bounded observation batches, explicit event
  preparation, published v1 schema and selected numeric OpenTelemetry span adapter.
- Measured onboarding/overhead, detector misses/false alarms and contributor,
  conduct, issue and security-reporting documentation.

No registry publication or hosted deployment. Operator verification is an
attestation. Semantic labels remain small/authored; production scale, independent
human calibration, SSO/MFA and tenants remain outside demonstrated evidence.
Terminal delivery history needs a storage policy; signing secrets need separate backup.
